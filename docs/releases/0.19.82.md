# Xachet 0.19.82

- **Material 3 Expressive 全界面重构与新图标**：应用全面切换至 Material 3 Expressive 原生界面，换装全新平面四色渐变香囊图标，引入 Google Sans Flex 与 MiSans 可变字体；内置 **韶峰红**、**湘水蓝**、**Legacy**（蓝粉双色）三套主题及壁纸动态取色，新增 `90%–120%` 全局界面缩放（默认 `110%`）。
- **番茄专注与实时活动**：内置番茄钟与正向长计时模式（顶栏实时显示下一节课详情、底栏长按弹出快捷菜单、内置专注统计与空教室入口）；新增专注实时活动，配备重绘白色钟表图标，番茄钟支持**停止 / 跳过**、长计时支持**暂停 / 继续 / 停止**按钮。
- **课表与桌面小组件优化**：支持删除自定义课程，取消课表老师显示并在各缩放档位下自动最大化课程标题与地点字号，“回到本周”改为快速重叠逐字弹跳动画；重构 2×2 与 4×2 Material 3 Expressive 桌面小组件并增加高度，主页本周课程格新增飞出展开动效。

适用于 Android 13 及以上，提供 ARM64 v8a、ARM v7a 和 x86_64 安装包，可直接覆盖升级 `0.19.79–0.19.81`。
