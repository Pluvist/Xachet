# Xachet 0.19.79

- Android 包名改为 `com.pluvist.xachet`。
- 优化课程卡片与课程状态栏详情的展开动画和玻璃背景性能。
- 调整课表显示、桌面组件及界面细节。

要求 Android 13 及以上，提供 ARM64 v8a、ARM v7a、x86_64 三种安装包。

## 安装与数据

本版作为独立应用安装，不能覆盖包名为 `com.pluvist.sachet.next` 的旧版。旧版账号、设置、课表缓存及桌面组件不会自动迁移；安装后请重新登录并添加组件。旧版可以暂时保留，确认新版数据与功能后再自行处理。

发布安装包应附 SHA-256 校验和与签名证书指纹。课表同步、教务查询、实时活动和桌面组件仍受学校接口、账号权限及系统后台策略影响。
